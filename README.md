# Reconnect 🌱

**Reconnect** is a cross-platform mental wellbeing application built with Flutter, designed to help users check in with themselves, build healthier habits, and stay connected to their mental health journey — anywhere, on any device.

## ✨ Features

- Chatbot to feel heard
- Guided breathing / mindfulness exercises
- Daily check-ins and reminders
- Progress insights and trends over time
- Cross-platform support: Android, iOS, Web, Windows, macOS, and Linux

## 🛠️ Tech Stack

- **Framework:** [Flutter](https://flutter.dev/)
- **Language:** Dart
- **Platforms:** Android · iOS · Web · Windows · macOS · Linux

## 🚀 Getting Started

### Prerequisites
- [Flutter SDK](https://docs.flutter.dev/get-started/install) installed and configured
- A connected device, emulator, or simulator (or a browser, for web)

### Installation

```bash
# Clone the repository
git clone https://github.com/arthporwal/Reconnect.git
cd Reconnect

# Install dependencies
flutter pub get

# Run the app
flutter run
```

To run on a specific platform:

```bash
flutter run -d chrome     # Web
flutter run -d windows    # Windows
flutter run -d macos      # macOS
flutter run -d linux      # Linux
```
